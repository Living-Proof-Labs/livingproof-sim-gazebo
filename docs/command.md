# Command reference

Generated by `task docs:reference`.

```text
usage: livingproof-sim-gazebo [-h] [--version] [--headless] [--steps STEPS]
                              [--timeout TIMEOUT] [--output OUTPUT]
                              [--render-output RENDER_OUTPUT]

Run the built-in falling-sphere world in Gazebo Harmonic without a display.

options:
  -h, --help            show this help message and exit
  --version             show package, provenance, and native engine versions
  --headless            run without a viewer (the default and only mode)
  --steps STEPS
  --timeout TIMEOUT     wall deadline in seconds
  --output OUTPUT       write trajectory JSON to this path
  --render-output RENDER_OUTPUT
                        capture a finite headless OGRE2 PNG at this path

Example: livingproof-sim-gazebo --steps 1000 --output
artifacts/trajectory.json. Engine execution does not prove robot capability.
```
